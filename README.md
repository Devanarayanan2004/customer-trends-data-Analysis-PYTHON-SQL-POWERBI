# 👨🏻‍💻 Customer Behavior Data Analyst Portfolio Project

This project represents a complete, industry-standard, **end-to-end data analytics workflow**, designed to mirror the real responsibilities of professional data analysts in modern business environments.

It covers every critical stage: data preparation, modeling, exploration, SQL-based business analysis, interactive visualization, insight generation, and stakeholder-ready reporting.

## 📌 Project Overview

The goal of this project is to transform raw customer shopping data into actionable business intelligence by:

- ✅ **Data Preparation, Cleaning & EDA** (Python) — cleaning, transforming, and exploring the raw dataset  
- ✅ **Business Analysis** (SQL) — answering real business questions about customer segments, loyalty, purchase behavior, and key drivers  
- ✅ **Visualization & Interactive Dashboard** (Power BI) — building a professional, filterable dashboard that tells the story of the data  
- ✅ **Reporting & Presentation** — summarizing findings, business insights, and recommendations in a clear report + presentation format

## 🛠️ Project Workflow

1. **Data Preparation & Exploration**  
   Open `Customer_Shopping_Behavior_Analysis.ipynb`  
   - Data import  
   - Initial exploration  
   - Data cleaning & transformation  
   - Load cleaned data into SQL database (MySQL / PostgreSQL / MS SQL Server)

2. **SQL Business Analysis**  
   Open `customer_behavior_sql_queries.sql`  
   - Run analytical queries to answer important business questions  
   - Focus: customer segmentation, purchase patterns, loyalty indicators, category performance, etc.

3. **Power BI Dashboard**  
   Open `customer_behavior_dashboard.pbix`  
   - Connect to the SQL database  
   - Build interactive visuals and KPI cards  
   - Add slicers, drill-throughs, and dynamic filters

4. **Final Deliverables**  
   - Professional project report (PDF / Word) summarizing insights & recommendations  
   - Stakeholder presentation deck (created using Gamma AI or PowerPoint)
